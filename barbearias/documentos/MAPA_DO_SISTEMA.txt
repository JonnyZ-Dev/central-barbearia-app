1. QUAL É O CÓDIGO FONTE QUE EU VOU MEXER PARA ATUALIZAR?
--------------------------------------------------------------------------------
O CÓDIGO FONTE É ÚNICO e fica na pasta raiz:
👉 E:\ChatBot_MensalistasAPP

Por que o código fonte é único?
Porque no modelo SaaS Profissional, você NUNCA divide o código em 10 projetos.
Se você fizer uma alteração em:
  E:\ChatBot_MensalistasAPP\src\app\page.tsx
essa melhoria é a versão oficial de TODAS as barbearias!

Quando você rodar o arquivo:
  E:\ChatBot_MensalistasAPP\barbearias\ferramentas\PUBLICAR_ATUALIZACAO.bat
ele sobe o seu código para o GitHub (https://github.com/JonnyZ-Dev/central-barbearia-app).
E TODOS os notebooks das barbearias (GM, Celebrite, Barbearia 3...) recebem a mesma
atualização automaticamente ao ligar ou no botão de Configurações!

O que diferencia uma barbearia da outra?
1. A Chave de Licença (no Supabase: LIC-GM-..., LIC-CELEBRITE-...).
2. O Banco de Dados SQLite (cada barbearia tem o seu no seu próprio notebook).
3. O WhatsApp conectado (cada barbearia tem o seu QR Code).
